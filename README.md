# 커뮤니티 이슈 클리핑 (community-clipping)

국내 주요 커뮤니티 인기글 중 **이슈가 될 만한 글**을 3시간마다 모아 보여주는 사이트입니다. 유지비 0원.

- 사이트: https://so0710eun-png.github.io/community-clipping/
- 수집: 디시인사이드(실시간 베스트), 보배드림(베스트), 웃긴대학(웃긴자료), 루리웹(베스트), 클리앙(모두의공원), 인스티즈(이슈), 뽐뿌(자유게시판 RSS)
- 수집 못 하는 곳: 에펨코리아(해외 서버 접속 차단), 더쿠(목록을 스크립트로 불러옴), 네이트판(robots.txt로 수집 금지)
- 본문·이미지는 저장하지 않고 **제목·링크·조회/추천/댓글 수**만 보여줍니다.

## 고칠 곳

| 하고 싶은 것 | 파일 |
|---|---|
| 걸러낼 단어 추가/삭제 | `scripts/filters.py` |
| 커뮤니티 추가, 화면 구조 바뀌어 수집 실패 시 수정 | `scripts/sources.py` |
| 화제 점수 기준 | `scripts/topic.py` |
| 실행 주기(기본 3시간) | `.github/workflows/collect.yml`의 `cron` |

## 화제 점수
- 같은 이야기(비슷한 제목)가 **여러 커뮤니티**에 올라올수록 높습니다. 1곳이면 최대 3점, 2곳이면 4점, 3곳 이상이면 5점입니다.
- 한 커뮤니티 안에서는 그 커뮤니티 기준 조회·추천·댓글이 상위 몇 %인지로 정합니다.
- 한 곳에만 있고 반응이 하위 30%인 글은 '반응 적은 글'로 기본 숨김 처리합니다.
